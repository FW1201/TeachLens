## 0. 執行前必讀（會直接影響判定）

1. **有些視窗截圖看不到。** 下列視窗刻意設為不被擷取（`NSWindow.sharingType = .none`），`screencapture`、會議分享、TeachLens 錄影都**不會**拍到它們：
   - 圖形工具列：`Sources/TeachLensCore/App/GraphicalTools.swift:272`
   - 玻璃提示 GlassToast：`Sources/TeachLensCore/App/GlassToast.swift` → `makePanel()`
   - 快捷鍵小卡：`Sources/TeachLensCore/Overlay/ShortcutCard.swift` → `makePanel()`
   - 錄影時的橘色邊框

   因此「截圖中沒有出現」**不等於失敗**。請改用其中一種方式驗證：
   - (a) 讀輔助使用（Accessibility）樹，找 `TeachLens 教學工具` 等元素；
   - (b) 對該位置點擊，看是否有反應；
   - (c) 標記為「需人工目視」，由使用者確認。

   反過來說，「截圖或錄影中**看不到**工具列」正是 J 組要驗證的預期結果。
2. **按鍵膠囊、字幕、課堂倒數、聚光燈**是學生要看到的，可以被截圖，用截圖判定。
3. 合成按鍵（computer use 送出的快捷鍵）若沒有反應，先到「設定 ▸ 總覽與測試 ▸ 快捷鍵接收測試」確認 TeachLens 有沒有收到，再判定功能本身是否失敗（見 I-08）。
4. 不要修改系統隱私權限以外的系統設定。測試結束後用 §2.3 恢復原狀。
5. **TeachLens 是選單列 App，沒有一般的「應用程式選單」。** ⌘, 只有在選單列的 TeachLens 選單打開時才有作用。要開設定，請點選單列的 TeachLens 圖示 ▸「設定…」。
6. **在畫布上拖曳**（白板畫線、拖曳圓鈕）若被操作工具擋下（例如 `AXError.notImplemented`），可改用支援低階滑鼠事件的方法，例如 `cliclick dd:/dm:/du:`，或把該案例標為「不可判定（工具限制）」，交給人工確認。

## 2. 準備與重置

### 2.1 安裝開發版
```bash
# 掛載 artifact 內的 TeachLens-Dev.dmg 後
ditto "/Volumes/TeachLens Dev/TeachLens (Dev).app" "/Applications/TeachLens (Dev).app"
xattr -dr com.apple.quarantine "/Applications/TeachLens (Dev).app"
open "/Applications/TeachLens (Dev).app"
```

### 2.2 回到「第一次開啟」狀態（A 組需要）

只刪 `hasCompletedFirstLaunch` **不夠**：只要還留著 `launchAtLogin` 或舊版選單列位置設定，App 就會把你當成老使用者，不會出現新手引導。判斷邏輯在 `Settings/SettingsStore.swift:290` `hasCompletedFirstLaunch` / `hasAnyExistingPreference`。

做法是先備份，再清除整個開發版的偏好設定網域：
```bash
osascript -e 'quit app "TeachLens (Dev)"'
defaults export io.github.fw1201.teachlens.dev ~/Desktop/teachlens-dev-prefs-backup.plist
defaults delete io.github.fw1201.teachlens.dev
```
測完用 `defaults import io.github.fw1201.teachlens.dev ~/Desktop/teachlens-dev-prefs-backup.plist` 還原。
其他相關 key：`keystrokeSettings`、`spotlightSettings`、`captionSettings`、`courseModes.current`、`courseModes.custom`、`presentationDisplayID`、`classCountdownMinutes`、`appLanguage`。

白板存檔：`~/Library/Application Support/TeachLens/whiteboard.json`。**測試前先備份**，測完還原。

### 2.3 測試後恢復
- 備份的 `whiteboard.json` 放回原處。
- 「設定 ▸ 課程模式」選回原本的模式。
- 關閉圖形工具列、聚光燈、字幕。
- `defaults delete io.github.fw1201.teachlens.dev presentationDisplayID`
- 若做過 §2.2，用 `defaults import` 還原備份。

## 3. 判定規則與證據

- 每個案例只判 **通過／失敗／不可判定／略過**。
  - 「不可判定」要寫明原因，例如「工具列不可被截圖」「合成按鍵未送達」。
  - 不要把「不可判定」寫成失敗。
- 證據檔名：`<案例編號>-<簡述>.png`，例如 `E-03-ctrl-c-windows.png`，放在 `docs/test-reports/evidence/1.3.0-beta.3/`。
- 時間相關的判定（例如 0.35 秒、1.2 秒、5 秒）用連續截圖或錄影粗估即可，誤差 ±0.3 秒算通過。

## 5. 已知限制（不算失敗）

- 開發版與正式版的權限分開，換版本後要重新授權。
- 螢幕錄製與輸入監控授權後，需要結束並重開 App 才生效。
- 0.35 秒與 1 秒這類時間值屬於體感設定。請記錄實際感受與建議值，不判定失敗。
- 已知待辦（下一輪）：錄影剪輯器仍使用 macOS 13 已棄用的影片 API（只有編譯警告，不影響功能）。
