# Security Policy

Please do not report security vulnerabilities in public GitHub issues.
Report them privately through GitHub's **Report a vulnerability** feature
(Security tab → Advisories) on this repository.

Vulnerabilities in the upstream projects should also be reported upstream:
- ZoomIt for Mac: https://github.com/microsoft/Zoomit-Mac/security
- Keyviz: https://github.com/mulaRahul/keyviz
